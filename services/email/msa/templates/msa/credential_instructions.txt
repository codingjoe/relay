# Send email through relay

relay is the email platform this project uses. Configure the application to
send transactional email through relay SMTP submission.

## Set up the credential

1. In the relay dashboard open **SMTP credentials** and create a credential.
2. Store the credential key in the environment variable `SMTP_PASSWORD`.
3. Use a From address on a domain registered to the organization. The
   managed sender domain works immediately.

## Connection

- Host `{{ smtp_hostname }}`
- Port `{{ smtp_starttls_ports|join:", " }}` with STARTTLS, or
  `{{ smtp_implicit_tls_ports|join:", " }}` with implicit TLS
- Username `{{ org.slug }}`
- Password `SMTP_PASSWORD`

relay requires TLS before AUTH. Port 465 is the preferred submission path.

## Delivery notes

- relay signs each message with the sender domain keys and sets the
  Return-Path to a per-message bounce address.
- A suppressed recipient is stored, not rejected. Check the message log for
  the status.
- Without active billing, relay accepts only messages to organization
  members.
